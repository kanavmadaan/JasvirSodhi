# Jasvir for Ward 2 — Georgetown Campaign Website

A new single-page, mobile-first campaign website built for Jasvir's Ward 2 city councillor campaign in Georgetown.

## Files
- `index.html` — complete campaign page
- `assets/styles.css` — desktop, tablet and phone responsive styles
- `assets/main.js` — sticky header/mobile navigation behaviour
- `assets/images/` — temporary photos copied from the prior Ward 4 site, as requested

## Replacing photos later
You can replace any image in `assets/images/` and keep the same filename, or change the corresponding `src` in `index.html`.

Current photo placeholders used:
- `1.jpg` — hero
- `11.jpg`, `12.jpg`, `13.jpg` — early community strip
- `8.jpg`, `14.jpg` — mission/vision collage
- `15.jpg`, `9.jpg`, `10.jpg` — community mosaic
